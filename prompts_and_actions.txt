RICE EXPORT MANAGER - DEVELOPMENT HISTORY & PROMPTS ENGINE SUMMARY

This document chronicles the complete development roadmap, earlier requests/prompts,

--------------------------------------------------------------------------------
PART 1: CENTRAL APPLICATION ARCHITECTURE & CONTEXT
--------------------------------------------------------------------------------
The Rice Export Manager is a full-stack, enterprise-grade multi-tenant web application
designed to manage agricultural grain export supply chains. It supports real-time
pricing, container calculations, packaging stocks, CFS and logistics, Proforma /
Commercial / Packing List generation, Firebase Cloud Authentication, OTP PIN locks,
licensing gates, and comprehensive inventory status checks.

Core System Stack:
- Frontend: React 18 / Vite / TypeScript / Tailwind CSS / Lucide Icons / Framer Motion
- Backend: Express Server with lazy-initialized production configuration
- Persistence: Firebase Firestore & Authentication with advanced security rules
- Deployment Environment: Sandboxed Cloud Run container on Port 3000 with nginx reverse proxy

PART 3: DIRECTORY MAP & FUNCTIONAL OWNERS
--------------------------------------------------------------------------------

1. ROOT DIRECTORY:
   - `package.json`         <- Directs npm dependencies and startup commands (dev / build / start).
   - `server.ts`            <- Handles static assets and server-side API endpoints on Cloud Run.
   - `metadata.json`        <- Primary application manifest containing metadata.
   - `firestore.rules`      <- Secure structural definitions for cloud tables.

2. SOURCE ROOT (`/src`):
   - `App.tsx`              <- The core router, tab controller, global state and Firebase auth hook.
   - `types.ts`             <- Absolute typing system for Quotes, Bags, Landings, and Inventories.
   - `storage.ts`           <- LocalStorage helper module fallback for offline configurations.
   - `constants.ts`         <- Seed defaults and core constants.

3. REACT COMPONENTS (`/src/components`):
   - `RateCalculator.tsx`   <- Live ex-mill pricing and packaging spec simulator.
   - `RateListBoard.tsx`    <- Unified spreadsheet showing calculated metric tons & bag totals.
   - `SavedQuotes.tsx`      <- List of all saved proformas and active status tags.
   - `DocumentWorkspace.tsx`<- Rich A4 container editor for invoices/packing lists.
   - `CfsTransport.tsx`     <- Local transport and port clearance costs.
   - `InventoryManager.tsx` <- Warehouse stock controller.
   - `BagPriceAndStock.tsx` <- Bag pricing models.
   - `DohaImport.tsx`       <- Surcharge landing calculations.
   - `VesselScheduleExplorer` <- Tracking transit lines.
   - `ContainerTracker.tsx` <- Container shipping milestones.
   - `OtpSecurityGate.tsx`  <- PIN matrix protection block.
   - `LicenceManager.tsx`   <- Active feature license switcher.
   - `AuthScreen.tsx`       <- User gatekeeper for cloud accounts.
